# HR Employee Attrition Dashboard

## 📊 Project Overview
This dashboard analyzes employee attrition patterns and workforce metrics.

## 🔧 Tools Used
- Power BI
- DAX
- Data Modeling

## 📈 Key KPIs
- Total Employees
- Attrition Count
- Attrition Rate

## 🔍 Key Insights
- Higher attrition in first 2 years
- Research & Development department shows higher exits
- Work-life balance impacts attrition
